AI Security Project

概要

Pythonを使用したネットワーク接続監視プログラムです。

ネットワークの接続状況を確認し、監視日時をログファイルに記録します。

使用技術
Python
Git/GitHub
Windows11
Visual Studio Code
TCP/IPネットワーク

実装済みの機能

TCPポート４４３への接続確認
接続成功・失敗の表示
監視日時の記録
ログファイルへの追記保存

今後の開発予定

接続成功・失敗のログ記録
異常な通信の検知
AIによる異常検知
セキュリティアラート
クラウド環境での監視

開発目的

Python、ネットワ－ク、セキュリティの知識を実践的に習得するために開発しています。

将来的にはAIとクラウド技術を組み合わせたセキュリティ監視システムへの発展を目指します。
