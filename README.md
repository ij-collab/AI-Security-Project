# AI Security Project

## 概要
Pythonを使用したネットワーク接続監視プログラムです。

## 使用技術
- Python
- Socket
- Git / GitHub
- Windows 11
- VS Code

## 実装した機能
- 現在日時の表示
- GitHubへのHTTPS接続確認
- 接続成功・失敗の判定
- ログファイルへの記録

## 今後の開発予定
- 不審な通信の検知
- AIによる異常検知
- クラウド環境での監視
- セキュリティ対策機能の追加

## 開発目的
Pythonとネットワークの基礎技術を学び、
セキュリティ監視システムの開発を目指しています。
